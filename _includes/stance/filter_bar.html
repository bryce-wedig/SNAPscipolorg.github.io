{%- comment -%} Renders a four-control filter bar (question / race / district / party). Inputs: include.scope — "state" or "global". When "state", the option lists are narrowed to values that appear in include.responses. include.responses — the array of stance_responses entries the filters apply to (used to prune options when scope == "state"). include.id_prefix — element id prefix, e.g. "state-filters" or "search-filters". Lets the same page host multiple bars if ever needed. {%- endcomment -%} {%- assign filters = site.data.stance_filters -%} {%- assign responses = include.responses -%} {%- assign id_prefix = include.id_prefix | default: "stance-filters" -%} {%- if include.scope == "state" -%} {%- assign present_questions = "" | split: "|||NONE|||" -%} {%- for r in responses -%} {%- if r.question.first -%} {%- assign present_questions = present_questions | concat: r.question -%} {%- else -%} {%- assign one_q = r.question | split: "|||NONE|||" -%} {%- assign present_questions = present_questions | concat: one_q -%} {%- endif -%} {%- endfor -%} {%- assign present_questions = present_questions | uniq -%} {%- assign present_races = responses | map: "race" | uniq -%} {%- assign present_districts = responses | map: "district" | uniq | compact -%} {%- assign present_parties = responses | map: "party" | uniq -%} {%- else -%} {%- assign present_questions = filters.questions -%} {%- assign present_races = filters.races -%} {%- assign present_parties = filters.parties -%} {%- endif -%}
